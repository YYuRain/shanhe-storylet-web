# 山河旅探 · 六章主线

非官方 AI 叙事试玩的独立网页前端，发布于 GitHub Pages。页面沿用现有试玩界面，包括自由对话、物证卡、回复反馈、回退和可调宽度的运行溯源面板。

## 运行结构

GitHub Pages 提供静态页面。页面通过固定的 Cloudflare API 入口连接本机 DSH 分享实例，剧情选择、角色演出、模型调用、人物记忆和状态结算仍全部由 DSH 执行。

本仓库只有前端，不包含完整剧本、角色卡、对话存档、模型密钥、桥接凭据或后台管理代码。试玩密码由服务端校验。

同一浏览器在此网页的访客身份保存在本地存储中，刷新可继续自己的进度。其他浏览器、设备以及旧入口各有独立身份；不会自动继承旧网址的存档。不要清除此网站的数据，否则无法自动恢复该浏览器的身份。

## 构建和发布

需要 Node.js 22 或更新版本。

```sh
npm ci
npm test
npm run build
```

`dist/` 是纯静态文件，使用相对资源地址，支持 GitHub Pages 的仓库子路径。GitHub Actions 在推送到 `main` 后构建并发布。后端地址统一配置于 `src/config.mjs`。

本机分享服务和联网需要保持可用。静态网页正常打开并不代表本机后端一直在线；暂时断线时页面会保留已保存的进度并尝试重连。

## 后续更新

DSH 引擎、剧情、物证内容和开场白从服务端实时获取，更新这些内容无需重新发布网页。修改前端界面时需同步相关 UI 源码并推送到本仓库；更换前端网址或 API 入口时需同时更新服务端精确的跨域来源许可。

本项目为《山河旅探》的非官方试玩界面，与原作开发商无隶属关系。
